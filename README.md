## Project Overview

This project explores how a LEGO website could exist if **every single UI element**
were physically “built” from LEGO bricks.

This is **not a mockup and not a template**:
all components are rendered and controlled live using HTML, CSS, and JavaScript.

The entire interface behaves like LEGO itself:
modular, editable, and dynamically rebuildable.

---

## Core Concept

The website is constructed from LEGO elements only:

- 2D LEGO pixel tiles
- 3D LEGO objects
- Hybrid 3D → 2D rendering
- Technic-inspired mechanical styles

Non-LEGO graphics are integrated via a **custom sticker system**, allowing any external
visual to be placed inside the LEGO environment as a modular element.

---

## Key Features

- Editable LEGO tiles (move, rotate, replace)
- SmartSnap system with LEGO-style stud alignment
- Sticker Book system with hundreds of stickers
- Switchable stud types (Standard, Technic, DUPLO
